# Basics.Tanlash — 1-amaliy vazifa (C# / .NET 8)

| Vazifa | Fayl | Tavsif |
|---|---|---|
| 1 | `Task1.cs` | `x > str.Length` bo'lsa `str` katta harflarga, aks holda kichik harflarga o'giriladi |
| 2 | `Task2.cs` | Ternary operator bilan yozilgan ifoda `if-else` orqali qayta yozilgan |
| 3 | `Task3.cs` | O'zbekcha hafta kuni inglizchaga `switch expression` yordamida o'giriladi |

## Ishga tushirish

```bash
dotnet run
```

So'ng vazifa raqamini (1, 2 yoki 3) tanlang.

## Misollar

```
x=13, str="teLefOn"   -> "TELEFON"
x=4,  str="komPyuter" -> "kompyuter"
x=15, y=10            -> x is greater than y
"payshanba"           -> Thursday
```
